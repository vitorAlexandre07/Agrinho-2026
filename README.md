# Agrinho-2026
🌾 Agro Forte - Futuro Sustentável

Site institucional sobre agricultura sustentável, inovação e tecnologia no campo.
O projeto apresenta uma empresa fictícia chamada Agro Forte, focada em soluções modernas para o agronegócio.

🚀 Sobre o Projeto

O Agro Forte é um site simples desenvolvido em HTML e CSS com foco em:

🌱 Agricultura sustentável
🚜 Tecnologias agrícolas modernas
🌍 Preservação ambiental
💧 Gestão eficiente de recursos naturais

O objetivo é demonstrar como o agronegócio pode ser moderno, sustentável e tecnológico.
